# Security

This pack is an **assessment engine**, not an attack platform.

- Do not file public issues with exploit PoCs, live CIDRs, or tokens.
- Orchestrator console binds `127.0.0.1` only.
- RiskReady wrap is WRAP_DEAD (no HTTP POST).
- Never POST `/api/risks`.
- Pack images do not embed nmap/nessus/nuclei.

Report product bugs to the named contact on the signed SCOPE sheet (Reid), not as a public MCP attack API.
